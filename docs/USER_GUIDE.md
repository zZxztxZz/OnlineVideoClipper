# 使用指南

## 保存素材

解析链接后先选清晰度和输出格式。完整视频无需建立片段；手动片段用 I / O 或起止时间框标记，再“添加片段”。快捷键仅在焦点不在输入框/播放器时生效，播放器占用焦点时可点击 I / O 按钮。

点击下载后，保存窗口列出每个文件的完整路径。可以直接改名，或使用“另存为…”选择位置和名称。扩展名须与当前输出格式一致；同名文件自动编号，不覆盖已有文件。最近一次成功加入队列的目录用于下一次保存，设置中的默认目录仍可独立修改。

兼容优先输出 MP4（仅音频为 M4A）；原始格式输出 MKV。快速片段保留原编码，精确片段重新编码。源无兼容编码时 MP4 可能需要转换。

## 同一播放器里选点和截图

播放、暂停、逐帧、起终点和截图共用同一个画面，不再弹出独立微调窗口。

1. 拖动时间轴定位，空格播放/暂停；蓝色表示已缓冲，绿色表示下载选区。
2. 暂停后按 ← / → 移动一帧，Shift 加方向键移动 5 帧；鼠标按钮同样可用。
3. 按 I 将当前画面设为第一帧，按 O 将当前画面设为最后一帧，两帧都会保留。
4. “查看 / 微调起点”“查看 / 微调终点”直接定位到该边界，在此状态逐帧移动会同步更新对应边界。
5. 点击“预览选区”检查，再“下载当前选区”，无需先加入列表；多个片段可以添加到列表后一起下载。

截图：暂停后直接选帧，在播放器右侧选择 PNG / JPG，点击“保存当前帧”选择路径和文件名。图片从源素材解码，保留所选清晰度的原尺寸，不包含播放器界面。预览代理和较小的显示图不参与最终图片导出。同名文件自动编号，成功保存后记住目录。

10 分钟以内的视频片段会补齐缺少的素材并按真实帧索引精确导出；已有缓冲直接复用，跨段会去重并检查连续性，完成后核对导出帧数。保存窗口显示准备进度，关闭可取消本次提交。容量不足时需降低清晰度或缩短选区。较长片段按所选切割方式下载，快速模式可能落到附近关键帧；完整视频和仅音频仍使用后台下载队列。

自动识别镜头功能已经移除。暂停后可直接按方向键逐帧移动，即使时间轴获得焦点也可用；输入文字和打开弹窗时不触发快捷键。普通播放和暂停不分析镜头，首次逐帧时才按需准备当前位置附近的真实帧索引。

## 连续播放与缓冲

播放器直接读取媒体流，收到可解码的数据就能播放，不等待某个片段完整下载，也不生成小段预览代理。正常观看时没有镜头扫描或 FFprobe 帧分析。

| 场景 | 行为 |
| --- | --- |
| 首次解析 | 读取媒体头和首批数据即可显示画面，不先准备整段素材 |
| 正常播放 | 播放器持续向后加载；前方已有约 45 秒时暂缓网络读取，缓冲减少后自动继续 |
| 暂停 | 目标保留约 8 秒前向缓冲，已经在途的数据可能继续到达 |
| 跳转 | 使用播放器的 Range 请求定位，直接读取目标位置，复用已有字节块 |
| 逐帧/截图 | 首次需要时准备附近真实帧索引，读取与预览相同格式时复用字节缓存，不寻找切镜、不制作代理；画面留在同一个播放器里 |
| 字节缓存 | `data/stream-cache`，目标上限 512 MiB；按最近使用和 24 小时回收 |
| 精确素材缓存 | 原有 `data/shot-cache` 保留用于选区导出，浏览索引目标 120 秒；下载选区可临时扩展至 10 分钟并受 512 MiB 限制 |

缓冲时长是控制目标，浏览器、媒体码率、关键帧和在途数据会影响实际范围。原素材缓存回收目标为 2 GiB / 24 小时，正在使用和队列依赖的素材受保护。缓存全部位于程序所在盘。

预览优先使用原生可播放的 AVC/AAC 流；源只有其他编码或分段协议时，可能需要选择其他清晰度或在原平台播放。预览采用 HTTP 代理，SOCKS 用户可使用代理客户端提供的 HTTP/混合端口。切换清晰度、跳到未读取的位置或首次逐帧仍可能等待。预览与导出使用不同源格式时不能复用所有字节。

## 平台连接

B站/抖音解析要求 Cookie 时：设置 → 连接平台 → 在独立窗口正常浏览、登录或完成验证 → 返回设置 → 完成连接 → 重新解析。取得 Cookie 不代表下载一定成功；接口变化可能需要更新下载引擎。程序只导出对应平台 Cookie 到本机，不读取 Chrome/Edge 等外部浏览器配置。也可导入 Netscape 格式 Cookie 文件。

YouTube 需要登录时可以在设置里配置自行取得的 Netscape Cookie 文件。平台 Cookie 与代理分别配置，B站/抖音代理留空默认直连。所有平台的素材预览和下载共用对应平台的代理与 Cookie 设置。

## 队列与后台

单项支持暂停、继续、取消和立即重试，等待项支持上下移动或优先下载。顶部“暂停启动新任务”只阻止后续任务启动，正在执行的任务继续。暂停状态与任务记录会保存。

完整视频保留临时文件并尽量续传，受协议与源限制；片段暂停后继续可能从该片段开头重下。精确镜头使用分析缓存重新执行本地导出。转换暂停后可能重新处理。

关闭主窗口缩到托盘，后台继续运行。点击托盘图标或再次启动 EXE 唤回原窗口；托盘菜单可以退出。失败记录会根据原因提供重新连接、重新解析/修改选项、更换保存位置或重试。

## 常见问题

- **启动失败/白窗口**：检查 WebView2 Runtime、目录写权限，查看 `data/desktop.log`；可用 `--browser` 诊断。不要只复制 EXE，要保留 `_internal` 和 `tools`。
- **预览失败但已解析**：源地址过期、网络失败或平台验证均可能导致预览失败。可重新解析，或在原平台确认时间后手动输入。
- **B站没有高分辨率**：只列出当前账号和源实际可用的格式，可连接有权限的账号后重新解析。
- **抖音要求验证**：重新连接并完成验证；仍失败时更新下载引擎。无法绕过登录权限，原视频已有标识不会被移除。
- **下载不能启动**：确认网络、平台代理、Cookie 及目录写权限；队列处于暂停启动时先恢复。
- **本地无法播放**：使用系统播放器；部分 MKV 编码不被 WebView2 支持。
- **进度没有百分比**：FFmpeg 区间下载可能没有总大小；处理速度和预计时间为估计值。

每个导出附带 `.source.json`，记录来源与时间段。分享素材和日志前先检查是否包含私人来源或本机路径。卸载便携程序前备份下载与配置，然后退出程序再删除整个文件夹。
